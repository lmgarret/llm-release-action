## What it does

<CardGrid>
  <Card title="Semantic version analysis" icon="seti:git">
    Reads the commits since the last semver tag, detects breaking changes from commit
    markers and diffs, and suggests `major`, `minor` or `patch`. Conservative: a major
    bump needs explicit evidence.
  </Card>
  <Card title="Multi-audience changelogs" icon="document">
    One run writes a changelog per audience (developer, customer, executive, marketing,
    security, ops) and per language, each with its own tone, sections and filters.
  </Card>
  <Card title="Any LLM provider" icon="puzzle">
    Works with every provider [LiteLLM](https://docs.litellm.ai/docs/providers) supports:
    AWS Bedrock, Anthropic, OpenAI, Azure and more. Reports token usage per model.
  </Card>
  <Card title="Net-state changelogs" icon="approve-check">
    A feature added then reverted doesn't show up. Related commits become one entry.
  </Card>
</CardGrid>
